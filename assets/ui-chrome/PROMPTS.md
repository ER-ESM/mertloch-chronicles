# GUI material family

Created with built-in `image_gen`, 2026-09-21. Original PNG pixels and alpha are preserved in `runtime/`. CSS and canvas use the same frame sprites; frame-brass uses a 22% nine-slice, frame-inset a 10% nine-slice. Portraits remain the existing authored character artwork, wrapped in the new transparent medallion.

## portrait-medallion

Use case: stylized-concept. Production transparent PNG game UI asset, a SINGLE empty circular portrait bezel centered in a square image. Premium hand-painted chunky pixel art for a rustic German village fantasy RPG, warm antique brass and aged bronze, deep forest green patina, strong dark outlines, pixel clusters rather than fuzzy texture. Large clean perfectly transparent circular hole occupying 72 percent of image width. The bezel occupies 96 percent of the image, near outer edges, NO background inside or outside the ring. Symmetric thick rim with modest carved oak insets, four polished brass rivets at diagonals, a tiny green enamel diamond at top, small decorative brass crest at bottom. Rich highlights from upper left, no excessive glow. Frame perfectly straight-on and round, no perspective. NO text, numbers, face, portrait, paper, shadow plane or checkerboard. Crisp and readable when used as an 80px player portrait frame. Genuine alpha transparency.

Warm rustic tavern fantasy RPG, exquisite hand-painted chunky pixel art, antique brass trim, dark verdigris green inset, oiled walnut rear edge. Frame runs FLUSH to all FOUR outer edges of image, no margin and no exterior shadow. Completely EMPTY TRANSPARENT rectangular central opening, from x=120 to904, y=120 to904. Rail thickness 56px along middle edges, elaborate fixed corners occupy only 120x120px with chunky brass rivets and tasteful dark oak carving. The straight middle 76 percent of each edge has perfectly uniform thin trim so it can STRETCH in a 9-slice UI to long narrow player panels and large windows. Distinct polished bevel highlights upper left, dark engraved grooves, legible at small UI scale, restrained luxury. No text, numbers, symbols in the center, content, icon, scene, checkerboard. Orthographic front view. Genuine alpha transparency in opening and tiny chamfered outer corner cutouts.
