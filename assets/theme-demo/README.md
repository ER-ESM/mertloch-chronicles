# Detaillierte Themen-Demo

Neue Bildmotive für Dosen-Dieter (Braumeister), Aperol-Anni (Zitrus-Alchemie) und Klo-Kevin (Pfand-Technik). Quellen und tatsächliche Prompts werden neben den Runtime-Exporten aufbewahrt. Die Motive ergänzen die bestehenden Spielgrafiken als eigenständige visuelle Demo.

Seite: `theme-demo.html`. Import: `node tools/prerender/build-theme-demo.mjs`. Quellen und Prompts: `sources/` und `generation.json`. Exportformat und Grenzen: [Dokumentation](../../docs/THEMEN-DEMO-2026-09-18.md). Gear ist in diesen Standansichten eingebaut; dies sind keine animierten GLB-Modelle.
